Consulta README.md para la instalación, las pruebas, la API y el despliegue.

Entrenar: python .\kfold.py --train --data Tweets.parquet --save kfold.joblib
Probar desde fichero: python .\kfold.py --predict-file tweets.txt --load kfold.joblib

Crear entorno virtual: python -m venv mi_entorno
Activar entorno virtual: sentiment_2\Scripts\activate
Requirements: pip install sentence-transformers lightgbm scikit-learn pandas joblib
